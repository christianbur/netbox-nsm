The search looks across all rulebooks and matches rules whose name or whose rulebook name contains the search term (case-insensitive).

deny Find all rules named "deny …" across every rulebook
TrustSec Show all rules inside rulebooks matching "TrustSec"
permit any Find rules containing the phrase "permit any"
